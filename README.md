# StockFlow – Inventory Management System

StockFlow is a full-stack inventory management application that helps organizations manage products and monitor stock levels.

## Live Demo
https://harmonious-buttercream-435f44.netlify.app/

## Technologies Used
- **Frontend:** Angular, TypeScript, HTML, CSS
- **Backend:** Java, Spring Boot
- **Database:** MySQL

## Features
- User registration and login
- Organization-level data isolation
- Product creation, updating, and deletion
- Inventory dashboard with stock summaries
- Low-stock alerts based on configurable thresholds
